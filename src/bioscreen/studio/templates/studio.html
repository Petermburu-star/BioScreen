▸ Reproduce this on your machine clone, build, run — same results

1. Clone the repository

git clone https://github.com/Petermburu-star/BioScreen
cd BioScreen

2. Install dependencies

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

3. Set your HuggingFace token

echo "HF_TOKEN=hf_your_token_here" > .env

Get a token at huggingface.co/settings/tokens and accept the license at biohub/ESMC-600M.

4. Build the reference and fingerprint files

python scripts/build_references.py
python scripts/build_fingerprints.py

5. Reproduce the ricin validation

python scripts/reproduce_ricin_test.py

Expected output: 3 EvoDiff variants, BLAST < 0.30 (evaded), fingerprint ≥ 0.85 (caught).

6. Launch this Studio

python scripts/start_studio.py

Then open http://127.0.0.1:5000.
